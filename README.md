A smart attendance and safety platform for Hajj pilgrims (graduation project, in progress).

- Flutter app (Android + Web) for pilgrims and supervisors, plus a web operations dashboard

- PostgreSQL on Supabase: 38 tables, 83 relationships, Row Level Security on every table
